# TechPoint на Bootstrap

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Сайт магазина смартфонов TechPoint, сделанный на Bootstrap. Предметная область та же, что в КР №1: каталог Samsung Galaxy S23, S23+ и S23 Ultra, страницы товаров и форма заказа.

## Ссылка на сайт

GitHub Pages: https://relaxagg.github.io/kr2-bootstrap-shop/

Можно также скачать репозиторий и открыть `index.html` в браузере.

## Фреймворк и подключение

Bootstrap 5.3.8, подключён локально, без CDN. Файлы лежат в папке `vendor/bootstrap/`:

- `vendor/bootstrap/css/bootstrap.min.css` — подключается в `head`
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — подключается в конце `body`

Свой файл `css/custom.css` подключается после Bootstrap, чтобы можно было переопределить стили.

## Структура

- `index.html` — главная: hero с каруселью, преимущества, популярные товары, вопросы (accordion), модальное окно заявки
- `catalog.html` — каталог с фильтрами
- `product.html`, `product-s23.html`, `product-s23-plus.html` — страницы товаров (S23 Ultra, S23, S23+)
- `order.html` — форма заказа
- `contacts.html` — контакты
- `css/custom.css` — свои стили
- `js/main.js` — отправка форм и сообщение об успехе
- `js/catalog.js` — фильтры каталога
- `js/product.js` — выбор памяти и цвета
- `images/` — фото товаров
- `vendor/bootstrap/` — Bootstrap

## Bootstrap-компоненты

- сетка: `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `row-cols-*`, `g-*`
- `navbar` с мобильным меню
- `card`
- `btn` (`btn-outline-dark`, `btn-outline-secondary`, свой `btn-orange`)
- `badge`
- `alert`
- `modal`
- формы: `form-control`, `form-select`, `input-group`, `form-check`
- `carousel`, `accordion`, `tabs`, `breadcrumb`, `list-group`, `table`

## Доработки

- Bootstrap подключён локально из `vendor/bootstrap/`
- страница «Контакты» и отдельная страница для каждой модели
- дополнительные компоненты: карусель на главной, вопросы в accordion, вкладки на странице товара
- рабочие фильтры в каталоге по модели и цене
- на странице товара можно выбрать память (512 ГБ дороже на 4 000 ₽) и цвет, цена пересчитывается
- кнопка «Заказать» на главной сразу подставляет модель в форму, а «Оформить заявку» на странице товара открывает форму заказа с выбранной моделью
- после отправки формы появляется `alert` с сообщением
- фильтры в каталоге прилипают при прокрутке на больших экранах, на телефоне сетка перестраивается в одну колонку

## Как проверить

1. Открыть главную, полистать карусель, раскрыть вопросы.
2. Нажать «Заказать» у телефона — откроется модальное окно с уже выбранной моделью.
3. Отправить пустую форму — поля подсветятся, заполненную — появится сообщение.
4. В каталоге отметить модель или цену и нажать «Показать».
5. На странице товара переключить 256/512 ГБ — цена изменится.
6. Сузить окно — появится кнопка мобильного меню.
